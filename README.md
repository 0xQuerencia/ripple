# ripple! 🦋

Little causes, big consequences. A handmade cause-and-effect playground.

## Development

```sh
npm install
npm run dev
```

## Current scope

Interactive design prototype with a seeded world and deterministic demo effects. No AI calls.

Based on the starter world and engine included in the supplied RIPPLE master specification. The reference image guides the scrapbook art direction; it is not used as the interface.
